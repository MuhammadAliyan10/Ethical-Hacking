# Networking Acronyms List

| Acronym | Full Form                                           | Description                                      |
| ------- | --------------------------------------------------- | ------------------------------------------------ |
| TCP     | Transmission Control Protocol                       | Reliable, connection-oriented transport protocol |
| UDP     | User Datagram Protocol                              | Fast, connectionless transport protocol          |
| IP      | Internet Protocol                                   | Logical addressing & packet routing protocol     |
| IPv4    | Internet Protocol Version 4                         | 32-bit IP addressing                             |
| IPv6    | Internet Protocol Version 6                         | 128-bit IP addressing                            |
| HTTP    | HyperText Transfer Protocol                         | Web communication protocol                       |
| HTTPS   | HyperText Transfer Protocol Secure                  | Encrypted HTTP                                   |
| FTP     | File Transfer Protocol                              | File transfer protocol                           |
| SFTP    | Secure File Transfer Protocol                       | Secure file transfer over SSH                    |
| SMTP    | Simple Mail Transfer Protocol                       | Email sending protocol                           |
| POP3    | Post Office Protocol v3                             | Email retrieval protocol                         |
| IMAP    | Internet Message Access Protocol                    | Advanced email retrieval protocol                |
| DNS     | Domain Name System                                  | Resolves domain names to IP addresses            |
| DHCP    | Dynamic Host Configuration Protocol                 | Assigns IP addresses automatically               |
| ARP     | Address Resolution Protocol                         | Maps IP to MAC address                           |
| RARP    | Reverse Address Resolution Protocol                 | Maps MAC to IP                                   |
| ICMP    | Internet Control Message Protocol                   | Network diagnostics (e.g., ping)                 |
| NAT     | Network Address Translation                         | Translates private IP to public IP               |
| LAN     | Local Area Network                                  | Small geographic network                         |
| WAN     | Wide Area Network                                   | Large geographic network                         |
| MAN     | Metropolitan Area Network                           | City-wide network                                |
| PAN     | Personal Area Network                               | Very small network (e.g., Bluetooth)             |
| WLAN    | Wireless Local Area Network                         | Wireless LAN                                     |
| VPN     | Virtual Private Network                             | Secure private network over internet             |
| VLAN    | Virtual Local Area Network                          | Logical network segmentation                     |
| MAC     | Media Access Control                                | Physical hardware address                        |
| ISP     | Internet Service Provider                           | Company providing internet access                |
| OSI     | Open Systems Interconnection                        | 7-layer networking model                         |
| TCP/IP  | Transmission Control Protocol / Internet Protocol   | Internet protocol suite                          |
| BGP     | Border Gateway Protocol                             | Internet routing protocol                        |
| OSPF    | Open Shortest Path First                            | Interior gateway routing protocol                |
| RIP     | Routing Information Protocol                        | Distance-vector routing protocol                 |
| EIGRP   | Enhanced Interior Gateway Routing Protocol          | Cisco advanced routing protocol                  |
| MPLS    | Multiprotocol Label Switching                       | High-performance routing technique               |
| QoS     | Quality of Service                                  | Traffic prioritization                           |
| VoIP    | Voice over Internet Protocol                        | Voice communication over IP                      |
| SSL     | Secure Sockets Layer                                | Encryption protocol (deprecated)                 |
| TLS     | Transport Layer Security                            | Secure communication protocol                    |
| SSH     | Secure Shell                                        | Secure remote login protocol                     |
| Telnet  | Telecommunication Network                           | Remote login protocol (insecure)                 |
| SNMP    | Simple Network Management Protocol                  | Network device management                        |
| NTP     | Network Time Protocol                               | Time synchronization protocol                    |
| CDN     | Content Delivery Network                            | Distributed content servers                      |
| IDS     | Intrusion Detection System                          | Monitors network threats                         |
| IPS     | Intrusion Prevention System                         | Blocks network threats                           |
| ACL     | Access Control List                                 | Network traffic filtering rules                  |
| MTU     | Maximum Transmission Unit                           | Largest packet size allowed                      |
| RTT     | Round Trip Time                                     | Time for packet to travel & return               |
| ISP     | Internet Service Provider                           | Internet service company                         |
| FQDN    | Fully Qualified Domain Name                         | Complete domain name                             |
| AAA     | Authentication, Authorization, Accounting           | Security framework                               |
| PPP     | Point-to-Point Protocol                             | Direct connection protocol                       |
| L2TP    | Layer 2 Tunneling Protocol                          | VPN tunneling protocol                           |
| PPTP    | Point-to-Point Tunneling Protocol                   | VPN protocol (older)                             |
| GRE     | Generic Routing Encapsulation                       | Tunneling protocol                               |
| STP     | Spanning Tree Protocol                              | Prevents network loops                           |
| RSTP    | Rapid Spanning Tree Protocol                        | Faster STP                                       |
| CSMA/CD | Carrier Sense Multiple Access / Collision Detection | Ethernet collision handling                      |
| CSMA/CA | Carrier Sense Multiple Access / Collision Avoidance | Wireless collision handling                      |
| AP      | Access Point                                        | Wireless network device                          |
| SSID    | Service Set Identifier                              | WiFi network name                                |
| NIC     | Network Interface Card                              | Hardware network adapter                         |
| SNR     | Signal-to-Noise Ratio                               | Signal quality measure                           |
| BER     | Bit Error Rate                                      | Transmission error rate                          |
| PoE     | Power over Ethernet                                 | Power delivery via Ethernet                      |
| SDN     | Software Defined Networking                         | Programmable networking architecture             |
| NFV     | Network Function Virtualization                     | Virtualized network services                     |
| IGP     | Interior Gateway Protocol                           | Internal routing protocol                        |
| EGP     | Exterior Gateway Protocol                           | External routing protocol                        |
| UTP     | Unshielded Twisted Pair                             | Network cable type                               |
| STP     | Shielded Twisted Pair                               | Shielded network cable                           |
| FDDI    | Fiber Distributed Data Interface                    | High-speed fiber network                         |
| ATM     | Asynchronous Transfer Mode                          | High-speed switching technology                  |
